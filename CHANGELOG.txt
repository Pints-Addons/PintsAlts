Pint's Alts - Changelog

v1.6.2
- Every session starts with your characters sorted by level, highest first (the character list and the table).
  A different sort you pick holds until you log out.

v1.6.1
- BiS tab: each slot's picks are numbered in order (1 = best).
- BiS tab: a dungeon filter shows only what drops in one dungeon or raid (wings count as their dungeon), with how
  many picks each has. The numbers keep each item's place in its slot.

v1.6
- New BiS tab (WoW Forever): best-in-slot gear for each character's spec and level bracket (20, 30, 40, 50, 60), from
  the WoW Forever BiS lists at wowtbc.gg. Each slot shows the picks with where they drop, the level needed, what you
  wear now, which of your characters already has one, upgrade % (with Pint's Craft Upgrades) and a wishlist star.
  Click to try one on. The spec comes from your talents (pick another from the spec button). It adapts to your
  level: the list for the bracket you've reached, plus every piece of the next bracket's list you can already use,
  so each level up adds more. Click a level button to see that whole list instead.
  Type any level (1-60) in the Level box to plan ahead; "Mine" goes back to your own level.
- Wishlist: a Share button sends the character's wishlist to another player (through Pint's Loot).
- The window, gear list and recipe book close when a fight starts, so they never hide what's attacking you
  (/alts combat keeps them open). The close buttons always work in combat.
- Wishlist on the Character tab (with Pint's Loot): see any character's wishlist, with upgrade % and where each item
  comes from; click one to try it on. Star items (or Alt-click them) in any slot's gear list to add them. It's the same
  wishlist as Pint's Loot's, so changes show in both.
- Gear list: Tab moves between the level boxes and the name filter (Shift-Tab goes back).
- Wishlist: three views - By slot (a heading per gear slot), By dungeon (a heading per dungeon), or Best % (one list,
  biggest upgrade first). Each item shows its name, slot and upgrade % with the boss and dungeon beneath.
- Gear list: a Search button (or Enter in a level box) looks again with the levels you typed; the count line says which
  levels it searched.
- WoW Forever: leather, mail and shield items were missing from the gear list for classes that can wear them (the game
  no longer lists armor skills), e.g. Naga Battle Gloves for a level 23 shaman. Now goes by the class instead.

v1.5
- WoW Forever: new Currencies view - every character's Merchant's Favor and Honor Points (and any other currency
  they have), with totals. Amounts save as they change, even with the Currency tab's groups folded.
- Skills: when a profession can go up a rank (or is capped), the next rank and where to learn it show under it -
  the trainer, or the book or quest for Fishing, Cooking and First Aid, with map coordinates and the book's price.
  Click it to point Pint's Quest Book's arrow there. A chat note tells you once when one is ready.
- WoW Forever: each character's talent spec is read again (the tree Pint's Tips shows), so Craft Upgrades scores
  their gear for the right role.

v1.4.2
- WoW Forever: money shows with the gold, silver and copper icons (the game's own coin text showed bare digits).

v1.4.1
- WoW Forever: characters are known by their full name (first and second, e.g. "Pint Waterboy"), so characters that
  share a first name no longer share one record. Classic Era is unchanged.
- Forever characters saved under a first name alone are cleared once; each saves itself again at its next login.

v1.4
- Works on WoW Forever (the modern game client). Classic Era is unchanged.
- Professions and skills are read from the modern profession list.
- Recipe books refresh when a profession window opens; game events a client doesn't have are skipped instead of erroring.

v1.3
- First public release.
- Ledger tab: Roster, Bag Space, Skills, Activity and Miscellaneous views for every character, with totals.
- Recipe books: click a profession on the Skills view to browse that character's recipes - skill-up colours,
  slot / type filter, search, auction prices, cost to make with vendor prices and raw materials, chat links.
- Characters tab: gear, stats, gear grid, bags, reputation, skills; try-on with stat changes; 3D model for the
  character you're on, race portraits for the others.
- Craft Upgrades tab (with the Craft Upgrades add-on): pick any character, or Craft for Alts.
- Item search across every character's bags, bank, mail and gear.
